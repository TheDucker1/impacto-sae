# Launcher vector controls

Original simple SVG artwork for the Saekano launcher, under the repository license.
The assets identify logical Vita controls; they are required UI resources, not
optional fallback decoration. vita.svg is a schematic control layout, without
manufacturer logos. All assets use viewBox plus circle/rect/line/polyline/polygon
primitives, allowing an existing vector renderer or a small strict primitive
loader to scale the actual SVG sources without font-dependent symbol glyphs.
Text labels accompany these assets in the editor. skip.svg denotes the PC skip
action separately from authored Vita buttons.
